# HoverTranslate

Переводчик «наведи и узнай» для Windows: английский → русский. Наведите курсор на слово в игре, браузере
или любой программе, нажмите **Alt+Q** — рядом появится карточка со словом, транскрипцией, переводом и
примерами. Всё работает на вашем компьютере, без интернета и без прав администратора.

- **Alt+Q** — слово под курсором (фразы вроде *give up* распознаются целиком, значение выбирается по контексту).
- Карточка показывает перевод всего предложения (модель opus-mt-en-ru, ONNX int8), озвучку 🔊, избранное ★.
- **Alt+W** — выделить область экрана: текст в ней распознаётся (Windows OCR, а если он читает плохо — запасной PaddleOCR) и переводится целиком.
- Боковые кнопки мыши можно назначить на слово / предложение / область.
- Окно «Словарь» (двойной щелчок по значку в трее): история и избранное, экспорт для Anki (CSV/TXT).
- Окно «Настройки»: горячие клавиши, вид карточки, голос, история и кэш, автозапуск, программы-исключения.

- **Необязательно — облачный перевод предложений через Google Gemini** (по умолчанию выключен): звучит естественнее встроенной
  модели на идиомах и тоне. Нужен бесплатный ключ из Google AI Studio (вводится в «Настройках», хранится только на вашем
  компьютере в зашифрованном виде). Встроенный перевод показывается сразу, облачный подменяет его, когда придёт; при ошибке,
  лимите или без сети остаётся встроенный. В облако уходят только предложения и области, не отдельные слова; **при включении текст
  с экрана отправляется в Google** (на бесплатном уровне Google может использовать запросы для улучшения своих моделей, кроме
  ЕС, Швейцарии и Великобритании).

Карточка не забирает фокус у игры и не попадает в снимки экрана (отключается в настройках).
Никакого внедрения в чужие процессы, хуков DirectX и чтения памяти: только захват экрана и UI Automation.
Полноэкранный режим: оконный режим и «окно без рамки» (borderless) — основной сценарий. В «настоящем» эксклюзивном
полноэкранном режиме DirectX кадр экрана может оказаться чёрным: тогда программа пробует другой способ захвата (BitBlt, затем
снимок самого окна игры) и пишет причину в лог; показать карточку поверх такой игры Windows тоже может не позволить.
Работает ли это в вашей игре, зависит от игры — если нет, включите в её настройках «окно без рамки».

## Установка

Требуется Windows 11 22H2 или новее, x64.

- **Установщик** `HoverTranslate-Setup-<версия>.exe` — ставит в `%LocalAppData%\Programs\HoverTranslate`,
  создаёт ярлык в меню «Пуск», по желанию — значок на рабочем столе и автозапуск. При удалении спрашивает,
  стереть ли историю и настройки.
- **Портативный архив** `HoverTranslate-<версия>-portable-win-x64.zip` — распаковать куда угодно и запустить
  `HoverTranslate.cmd` (сама программа лежит в папке `app`, её `app\HoverTranslate.exe` можно запускать и напрямую). История, избранное и настройки всё равно хранятся в `%LocalAppData%\HoverTranslate`.

Программа живёт в трее. Правый щелчок по значку — меню; «Настройки…» и «Словарь» открываются оттуда.
Логи — `%LocalAppData%\HoverTranslate\logs`.

## Сборка

Нужны .NET SDK 10 (см. `global.json`), [Inno Setup 6](https://jrsoftware.org/isinfo.php) и готовые данные в `data/`
(их делает `tools/DataBuilder`, см. [его README](tools/DataBuilder/README.md); в git данные не хранятся).

**Релиз** (тесты → publish → портативный zip → установщик; результат в `artifacts\dist`):

```powershell
.\build.ps1                 # полный релиз (Release, self-contained, win-x64, ReadyToRun)
.\build.ps1 -SkipTests      # без тестов
.\build.ps1 -SkipInstaller  # без Inno Setup (только publish и zip)
.\build.ps1 -Version 0.2.0  # другая версия (по умолчанию из Directory.Build.props)
```

Готовые файлы появятся в `artifacts\dist`:

- `HoverTranslate-Setup-<версия>.exe` — установщик (нужен Inno Setup 6; без него используйте `-SkipInstaller`);
- `HoverTranslate-<версия>-portable-win-x64.zip` — портативная версия: распаковать и запустить `HoverTranslate.cmd` (программа — в папке `app`);
- `SHA256SUMS.txt` — контрольные суммы.

Папка `artifacts\publish` — промежуточный результат (из неё делаются zip и установщик), выдавать её не нужно.

**Отладка** (Debug-сборка, вывод в `src\HoverTranslate.App\bin\x64\Debug\net10.0-windows10.0.22621.0\win-x64`):

```powershell
dotnet build HoverTranslate.sln                              # собрать всё в Debug
dotnet build HoverTranslate.sln -c Release                   # то же в Release, без publish и установщика
dotnet run --project src\HoverTranslate.App                  # собрать и запустить приложение (Debug)
dotnet run --project src\HoverTranslate.App -- --debug       # то же с флагом --debug (подробный лог, ocr-debug)
dotnet test --solution HoverTranslate.sln                    # автотесты
dotnet test --solution HoverTranslate.sln --filter-method "*Имя*"  # часть тестов
```

Можно и просто открыть `HoverTranslate.sln` в Visual Studio / Rider и запустить проект `HoverTranslate.App` (F5).
Данные из `data\` копируются рядом с exe автоматически, поэтому без готовых данных приложение не стартует.
Экземпляр может быть только один: перед запуском закройте уже работающий HoverTranslate (значок в трее → «Выход» или `HoverTranslate.exe --quit`).
